# {{COMPANY_NAME}} Agent Index

**When Superpowers needs domain expertise:**
This index lists available specialists. Spawn via `Agent(subagent_type="agent0-for-superpowers-{{COMPANY_NAME}}:<agent-name>")`.

## Available Agents

**Engineering:**
- **Software-Engineer**: {{COMPANY_NAME}} development practices, tech stack guidance, code patterns
- **Software-Engineer-In-Test**: Test strategy, coverage requirements, testing best practices, DoD certification
- **DevOps-Engineer**: CI/CD pipelines, deployment automation, infrastructure as code

**Security:**
- **Security-Engineer**: Post-implementation security reviews, vulnerability remediation, SAST/dependency scanning
- **Security-Architect**: Pre-implementation security design, threat modeling, compliance requirements

**UX:**
- **UX-Specialist**: Component design, accessibility reviews, design system application
- **Technical-Writer**: User-facing documentation, API docs, technical writing standards

**Product:**
- **Product-Manager**: Feature prioritization, user story refinement, roadmap alignment

## When to Consult

- **Before merge**: Security-Engineer for policy compliance
- **UI changes**: UX-Specialist for accessibility and design system
- **New features**: Security-Architect for threat modeling
- **Test strategy**: Software-Engineer-In-Test for coverage and DoD
- **Deployment**: DevOps-Engineer for CI/CD and infrastructure
- **Documentation**: Technical-Writer for user-facing content

## Customization

Replace `{{COMPANY_NAME}}` with your company name and update agent descriptions with your company's actual tools and processes.
