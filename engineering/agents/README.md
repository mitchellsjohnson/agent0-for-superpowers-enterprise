# Engineering Agents

Generic agent definitions for engineering roles. Customize with your company's tools and processes.

## Available Agents

- **Software-Engineer.md**: Development practices, tech stack, code patterns
- **Software-Engineer-In-Test.md**: Test strategy, coverage, DoD
- **DevOps-Engineer.md**: CI/CD, deployment, infrastructure

## Customization

Replace placeholders:
- `{{COMPANY_NAME}}` → Your company
- `{{COMPANY_SAST_TOOL}}` → Your SAST tool (e.g., Fortify, SonarQube)
- `{{COMPANY_DEPENDENCY_SCANNER}}` → Your dependency scanner (e.g., Lifecycle, Snyk)
- `{{COMPANY_ARTIFACT_REPO}}` → Your artifact repository (e.g., Nexus, Artifactory)
- `{{COVERAGE_THRESHOLD}}` → Your required test coverage percentage (e.g., 80)
